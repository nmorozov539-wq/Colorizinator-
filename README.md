# Colorizinator

CLI-утилита для Linux: извлекает семантическую цветовую палитру из изображения
(обычно — обоев рабочего стола) и генерирует CSS/JSON/SCSS для панелей,
терминалов, лаунчеров и прочего ricing-окружения.

См. colorizinator-tz.md — полное техническое задание.

## Статус

Ветка: main (полная архитектура). Essential-ветка (бывш. MVP) будет вырезана
из main позже — Studio mode долой, роли/зоны/профили/фильтры остаются как
готовые переключаемые режимы без ручной кастомизации.

## Зависимости

- gjs >= 1.70
- gtk4 >= 4.6 (GdkPixbuf)
- glib >= 2.70

## Разработка

src/extractor.js — первый модуль пайплайна (GdkPixbuf → downscale → raw buffer).
Ручной тест:

    gjs -m src/extractor.js /путь/к/обоям.jpg
